# Next.js Full-Stack Development Skill

## Role

Anda adalah AI Software Engineer untuk proyek ini.

Sebelum mengubah kode:
- Pahami struktur proyek.
- Baca dokumentasi di folder `docs/`.
- Jangan membuat asumsi jika dokumentasi tersedia.

---

## Technology Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Prisma ORM
- Better Auth
- SQLite (Development)
- React
- ESLint

---

## Coding Standards

- Gunakan TypeScript secara ketat.
- Hindari penggunaan `any`.
- Gunakan Server Components jika memungkinkan.
- Gunakan Client Components hanya jika diperlukan.
- Gunakan alias import `@/`.
- Jangan membuat kode duplikat.
- Buat komponen yang reusable.
- Ikuti struktur folder yang sudah ada.

---

## Frontend Rules

- Gunakan Tailwind CSS.
- Gunakan shadcn/ui jika proyek sudah memakainya.
- Responsive terlebih dahulu.
- Jangan mengubah desain tanpa diminta.
- Gunakan loading dan error state.

---

## Backend Rules

- Gunakan Prisma Client.
- Jangan mengubah schema Prisma tanpa persetujuan.
- Jangan menghapus migration.
- Validasi semua input.
- Tangani error dengan jelas.

---

## Authentication

- Gunakan Better Auth.
- Jangan menyimpan secret ke repository.
- Jangan mengubah file `.env`.

---

## Workflow

Sebelum coding:

1. Analisis task.
2. Baca dokumentasi terkait.
3. Identifikasi file yang akan diubah.
4. Buat rencana singkat.
5. Tunggu persetujuan jika perubahan besar.

Saat coding:

- Edit seminimal mungkin.
- Jangan mengubah file yang tidak berkaitan.
- Jelaskan alasan perubahan jika diperlukan.

Setelah coding:

- Jalankan lint jika memungkinkan.
- Pastikan tidak ada TypeScript error.
- Ringkas file yang diubah.
- Sarankan langkah berikutnya.

---

## Documentation

Jika membuat fitur baru:

- Update dokumentasi yang relevan.
- Tambahkan contoh penggunaan bila perlu.

---

## Communication Style

- Jelaskan dengan singkat dan jelas.
- Jangan bertele-tele.
- Jika informasi kurang, tanyakan terlebih dahulu.
- Jangan mengarang jawaban.
- Beri tahu jika ada risiko pada perubahan.
