## 3. Struktur Folder Frontend

Alias import: `@/*` → root proyek. Tidak ada folder `src/`.

```text
app/
├── (public)/            # Portal, falak, verifikasi QR, form permohonan publik
├── (auth)/              # login, forgot/reset password
├── (dashboard)/         # layout sidebar
│   ├── admin/           # Pusat: OWNER, ADMIN_*, TIM_WAJIB_KHIDMAH, CONTENT_MANAGER
│   ├── organisasi/      # PW, PC, PONDOK_INTERNAL, LEMBAGA_EKSTERNAL
│   └── personal/        # GURU_BANTU, PENGAJAR_*, DELEGASI_*, PANITIA_*
├── api/                 # HANYA endpoint publik & webhook
├── layout.tsx
└── globals.css          # token Tailwind v4 (@theme)

components/
├── ui/                  # shadcn/ui (jangan edit manual)
├── forms/               # FormField, ActionForm, FileUpload, ...
├── data/                # DataTable, Pagination, FilterBar, StatusBadge, ...
└── layout/              # Sidebar, Navbar, Footer, PageHeader, Breadcrumb

hooks/                   # custom hooks (alias @/hooks dari components.json)

modules/<domain>/presentation/
├── actions/             # Server Actions
├── queries/             # query untuk Server Component
└── components/          # komponen khusus domain (mis. LetterTable)
```

Status saat ini: `app/` baru berisi `page.tsx` (uji koneksi Neon) dan `dashboard/`. Route group di atas belum dibuat — `[ISI: tandai progres]`.

## 4. Server Component vs Client Component

Default: **Server Component**. Tambahkan `'use client'` HANYA jika memerlukan interaktivitas browser.

| Kebutuhan | Gunakan |
| :--- | :--- |
| Menampilkan data dari database | Server Component + query dari `modules/*/presentation/queries` |
| Form submit | Client Component kecil + Server Action (`useActionState`) |
| State UI lokal (modal, tab, dropdown) | Client Component |
| Animasi Framer Motion | Client Component (bungkus sekecil mungkin) |
| Session di server | `getSession()` dari `@/lib/auth` |
| Session di client | `useSession()` dari auth client |

Aturan:
- Dorong `'use client'` serendah mungkin di pohon komponen; jangan tandai seluruh halaman.
- Loading state memakai `<Suspense>` dan `loading.tsx`, bukan flag manual berlapis.
- `params` dan `searchParams` adalah Promise → WAJIB `await`.

---

## 5. Aturan Batas (Boundary Rules)

- UI **tidak boleh** mengimpor `@/generated/client` atau Prisma.
- `presentation/` hanya bicara ke `application/`, tidak langsung ke Prisma.
- Komponen lintas domain ditaruh di `components/`; komponen satu domain di `modules/<domain>/presentation/components/`.
- Jangan mengimpor `infrastructure/` modul lain.
- Data sensitif (password, token) tidak boleh sampai ke props Client Component.

## 7. Larangan Keras

- ❌ DILARANG membuat `pages/` directory atau `tailwind.config.ts`.
- ❌ DILARANG `useMemo`/`useCallback`/`memo()` manual (React Compiler aktif).
- ❌ DILARANG edit manual `components/ui/*` — perluas lewat wrapper.
- ❌ DILARANG `fetch('/api/...')` dari client untuk mutasi internal (gunakan Server Action).
- ❌ DILARANG hardcode role/levelCode/enum di UI (ambil dari enum Prisma/helper permissions).
- ❌ DILARANG mengandalkan UI untuk keamanan (otorisasi tetap di server).
- ❌ DILARANG `any` dan `console.log` tertinggal.
- ❌ DILARANG menaruh secret di variabel `NEXT_PUBLIC_*`.
- ❌ DILARANG menambah library UI tanpa ADR.
