Hasil pemeriksaan kontras (rasio WCAG, dihitung dari nilai oklch):

| Pasangan | Light | Dark | Lolos AA (4.5) |
| :--- | :--- | :--- | :--- |
| `*-foreground` di atas `--success` | 4.7 | 4.6 | ✅ (tipis) |
| `*-foreground` di atas `--warning` | 7.0 | 8.7 | ✅ |
| `*-foreground` di atas `--info` | 5.5 | 5.1 | ✅ |
| `--primary-foreground` di atas `--primary` | 4.9 | 6.9 | ✅ |
| Token sebagai **teks** di atas `--background`: success / info | 4.9 / 5.9 | 6.1 / 7.3 | ✅ |
| Token sebagai **teks**: `--warning` | **2.1** | 11.5 | ❌ di light |
| Token sebagai **teks**: `--primary` | 5.2 | **2.7** | ❌ di dark |

Aturan pemakaian dari hasil di atas:
- **Badge solid**: `bg-<token> text-<token>-foreground` (aman semua).
- **Badge lembut**: `bg-<token>/15` + teks `text-<token>` untuk success/info/destructive. Untuk **warning**, teks WAJIB `text-warning-foreground` (jangan `text-warning` di light mode).
- **Primary sebagai teks/link/ikon di dark mode**: jangan pakai `--primary` (2.7:1). Gunakan nada lebih terang `oklch(0.705 0.213 47.604)` (kontras 6.8:1; nilai sama dengan `--sidebar-primary` dark) — mis. lewat token baru `--primary-text`.
- Warna status selalu disertai teks/ikon, tidak berdiri sendiri.

Catatan:
- Alias `--admin-*` (AGENTS.md §10) belum ada. Putuskan apakah tetap dipakai atau cukup token global + `sidebar-*`: `[ISI]`.
- Radius dasar `0.875rem` membuat tampilan cukup membulat; sesuaikan bila terasa terlalu lembut untuk dashboard padat.

Dark mode: variabel `.dark` sudah tersedia dan custom variant `dark` bertipe **class** (`.dark`), bukan `prefers-color-scheme`. Belum ada mekanisme penerapan class tersebut. Keputusan: `[ISI: toggle manual + simpan preferensi / ikuti sistem / tidak ada di MVP]` (mis. `next-themes` — wajib ADR).

## 6. Motion

Library: Framer Motion v12 (Client Component saja).

- **Prinsip:** hanya untuk transisi dan umpan balik; tanpa animasi dekoratif.
- **Durasi:** hover 150ms · UI (dropdown, tab) 200ms · modal/drawer 300ms · halaman 400ms (maks)
- **Easing:** `ease-out` untuk masuk, `ease-in` untuk keluar — `[ISI: kurva kustom]`
- **Pola:**
  - Modal/drawer: fade + translate kecil
  - Sidebar mobile: slide dari kiri
  - Daftar/tabel: tidak dianimasikan per baris (hindari beban pada data banyak)
  - Loading: skeleton, bukan spinner penuh halaman
  - Toast: slide singkat
- **Aksesibilitas:** WAJIB hormati `prefers-reduced-motion` (matikan atau ganti dengan fade).
- Halaman publik (portal, landing): satu urutan masuk di hero (`Stagger`, ±0,4s), fade rute 200ms (`PageFade`), busur matahari berjalan sekali saat jadwal termuat (≤1,4s), dan respons atas aksi pengguna (pilihan waktu, tanda centang verifikasi). Tidak ada animasi per-seksi saat scroll.
- Semua animasi dibungkus `MotionProvider` (`reducedMotion="user"`); elemen bertanda `data-motion` dipaksa terlihat saat JavaScript nonaktif (`<noscript>` di `app/(public)/layout.tsx`).
- Motion Primitives / registri pihak ketiga tidak dipakai: Framer Motion langsung sudah cukup dan menghindari dependensi tambahan.

## 7. Responsif

Status repo: belum ada layout atau halaman responsif (baru scaffold `app/page.tsx` dan `app/dashboard/`). Bagian ini menjadi spesifikasi yang harus dipenuhi saat halaman dibuat.

### 7.1 Prinsip
- **Mobile-first**: tulis gaya dasar untuk layar kecil, lalu tambah `sm:`, `md:`, `lg:`, `xl:`.
- Target perangkat: mobile (≥360px), tablet, laptop, desktop.
- Tidak boleh ada scroll horizontal pada halaman (kecuali di dalam komponen tabel/kode yang sengaja scroll).
- Isi tetap sama di semua ukuran; yang berubah hanya susunan dan kepadatan.

### 7.2 Breakpoint (default Tailwind v4)

| Prefix | Lebar min | Perangkat | Perilaku utama |
| :--- | :--- | :--- | :--- |
| (dasar) | 0 | Mobile | Satu kolom, sidebar jadi drawer, tabel jadi kartu |
| `sm` | 640px | Mobile besar | Padding lebih lega, tombol aksi berdampingan |
| `md` | 768px | Tablet | Form dua kolom, grid kartu 2 kolom, sidebar mode ikon |
| `lg` | 1024px | Laptop | Sidebar penuh, tabel penuh, grid 3 kolom |
| `xl` | 1280px | Desktop | Lebar konten dibatasi, panel samping opsional |
| `2xl` | 1536px | Layar besar | Konten tetap di tengah, jangan melebar tanpa batas |

Hook `use-mobile` bawaan sidebar shadcn biasanya memakai batas 768px — samakan dengan `md`.

### 7.3 Layout Dasar

| Elemen | Mobile | Tablet (`md`) | Laptop+ (`lg`) |
| :--- | :--- | :--- | :--- |
| Sidebar dashboard | Drawer (`Sheet`) dibuka dari tombol menu di `Topbar` | Mode ikon (collapsed) | Penuh, bisa di-collapse |
| `Topbar` | Menu, judul halaman, avatar | + pencarian | + `ScopeIndicator`, notifikasi |
| Padding konten | `p-4` | `p-6` | `p-8`, lebar maks `[ISI: mis. max-w-7xl]` |
| Navbar publik | Menu hamburger | Menu horizontal ringkas | Menu penuh |
| Footer | Satu kolom | Dua kolom | Tiga–empat kolom |

### 7.4 Pola Komponen

| Komponen | Mobile | Laptop+ |
| :--- | :--- | :--- |
| `DataTable` | Kartu bertumpuk (kolom kunci: judul, status, tanggal; sisanya di "Lihat detail") atau scroll horizontal dengan kolom pertama tetap | Tabel penuh |
| `FilterBar` | Tombol "Filter" membuka `Sheet`; pencarian tetap di atas | Inline satu baris |
| `Pagination` | Prev / Next + "Hal. 2 dari 5" | Nomor halaman lengkap |
| `PageHeader` | Judul di atas, aksi utama penuh lebar di bawah | Judul kiri, aksi kanan |
| Form | Satu kolom, tombol simpan **sticky di bawah** layar | Dua kolom (`md+`), tombol di akhir form |
| `Dialog` | Jadi `Sheet` dari bawah (full width) | Dialog tengah |
| Dashboard metrik | Kartu satu kolom, chart tinggi tetap | Grid 2–4 kolom |
| `StatusBadge` | Tetap terlihat, jangan dipotong | — |

### 7.5 Tipografi & Sentuh
- Ukuran teks dasar 16px (mencegah zoom otomatis iOS pada input).
- Judul halaman: `text-xl` di mobile → `text-2xl`/`text-3xl` mulai `md`/`lg`.
- Target sentuh minimal 44×44px; jarak antar target minimal 8px.
- Hindari interaksi yang hanya bisa lewat hover; sediakan padanan tap/fokus.
- Input memakai `type`/`inputmode` yang tepat (email, tel, numeric) agar keyboard sesuai.

### 7.6 Prioritas Mobile per Halaman

| Halaman | Prioritas | Alasan |
| :--- | :--- | :--- |
| `/login`, form publik permohonan | Tinggi | Sering dibuka dari ponsel |
| Input laporan (WK mingguan, Safari harian, Pesantren harian) | Tinggi | Diisi di lapangan oleh guru/delegasi/pengajar |
| `/falak`, artikel, verifikasi QR | Tinggi | Publik, dibuka lewat ponsel (QR) |
| Daftar & approval jurnal/laporan | Sedang | |
| Persuratan, kepengurusan, CMS, konfigurasi falak | Sedang–Rendah | Terutama desktop; tetap harus bisa dipakai di tablet |

`[ISI: koreksi prioritas sesuai kebiasaan pengguna]`

### 7.7 Pengujian Responsif
Viewport uji minimum: 360×800 (mobile), 768×1024 (tablet), 1280×800 (laptop), 1920×1080 (desktop). Lihat `07.TESTING.md`.

## 8. Aksesibilitas

Standar: **WCAG 2.1 AA**.

- Kontras teks 4.5:1 (teks besar 3:1)
- Semua fungsi bisa dijangkau keyboard; fokus selalu terlihat
- `aria-*` benar pada modal, tab, dropdown, dan status dinamis (`role="status"` untuk pesan hasil aksi)
- Setiap input punya `label`; error form terhubung via `aria-describedby`
- Gambar bermakna punya `alt`
- Blok Arab memakai `lang="ar"` dan `dir="rtl"`

## 9. Larangan Keras

- ❌ DILARANG hardcode warna/spacing (gunakan token).
- ❌ DILARANG membedakan status hanya dengan warna.
- ❌ DILARANG memakai `text-warning` di light mode atau `text-primary` di dark mode sebagai teks (kontras < 4.5:1).
- ❌ DILARANG halaman dengan scroll horizontal atau tabel lebar tanpa pola mobile (kartu/scroll terkontrol).
- ❌ DILARANG animasi dekoratif atau yang mengabaikan `prefers-reduced-motion`.
- ❌ DILARANG edit manual `components/ui/*`.
- ❌ DILARANG string antarmuka tersebar tanpa konsistensi istilah — gunakan daftar istilah baku `[ISI]`.
