## 1. Tujuan

Katalog komponen agar tidak ada duplikasi. Sebelum membuat komponen baru, cek daftar ini terlebih dahulu.

---

## 2. Lapisan Komponen

| Lapisan | Lokasi | Aturan |
| :--- | :--- | :--- |
| Primitive | `components/ui/` | Dari shadcn/ui. Jangan edit manual |
| Wrapper/komposit | `components/forms/`, `components/data/`, `components/layout/` | Memperluas primitive, memakai token |
| Domain | `modules/<domain>/presentation/components/` | Boleh tahu istilah domain; tidak mengimpor Prisma |
| Halaman | `app/**/page.tsx` | Menyusun komponen, memanggil query |

---

## 3. Primitive shadcn/ui

Preset sudah diinisialisasi (`style: base-luma`, **Base UI**, ikon lucide). `components/ui/` belum berisi komponen — tambahkan lewat CLI (`bunx --bun shadcn@latest add <nama>`) dan catat di sini. Karena Base UI, komposisi memakai prop `render`, bukan `asChild`.

| Komponen | Terpasang | Catatan |
| :--- | :--- | :--- |
| Button, Input, Textarea, Label | ✅ | |
| Select, Checkbox, Radio, Switch | ✅ | |
| Dialog, Sheet, Dropdown Menu, Popover | ✅ | |
| Table, Tabs, Badge, Card | ✅ | |
| Tooltip, Skeleton, Sonner/Toast | ✅ | `Toaster` sudah dipasang di `app/layout.tsx` |
| Calendar/Date Picker | ✅ | react-day-picker; penting untuk periode & tanggal laporan |

## 4. Komponen Layout

| Komponen | Fungsi | Catatan |
| :--- | :--- | :--- |
| `Sidebar` | Menu dashboard per role | Dibangun dari izin role (`nav-config.ts`); drawer di mobile (`MobileNav`); mode ikon di `md`, bisa diciutkan di `lg` (cookie `lim-sidebar`) |
| `Topbar` | Judul, pencarian, menu akun | Menampilkan konteks organisasi/periode aktif |
| `Navbar` / `Footer` | Halaman publik | |
| `PageHeader` | Judul, deskripsi, aksi utama, breadcrumb | |
| `Breadcrumbs` | Navigasi hirarki dari pathname (`breadcrumb-trail.ts`) | Segmen pengelompok tidak ditautkan; tersembunyi di Ringkasan |
| `ScopeIndicator` | Menampilkan scope data: "Pusat", nama unit organisasi, atau "Data pribadi" | Di `Topbar` mulai `lg`; sumber data `getUserScopeQuery`. Penanda tampilan, bukan pengamanan |
| `AdminHeader` | Header Konsol Pusat (OWNER): logo, pencarian, notifikasi, menu akun | `app/dashboard/layout.tsx` untuk role `OWNER` |
| `ModuleNav` | Navigasi modul horizontal Konsol Pusat | Daftar item dari `getNavGroups(role)`, bukan daftar terpisah |

## 6. Komponen Data

| Komponen | Fungsi | Catatan |
| :--- | :--- | :--- |
| `DataTable` | Tabel dengan sort & kolom | Sort/filter lewat URL |
| `Pagination` | Mengikuti `page` & `limit` (default 20, maks 100) | |
| `FilterBar` | Pencarian `q`, status, rentang tanggal | State di `searchParams` |
| `StatusBadge` | Memetakan enum → varian | Lihat `02.DESIGN_SYSTEM.md` §5 |
| `EmptyState` | Tidak ada data + aksi berikutnya | |
| `ErrorState` | Gagal memuat + coba lagi | Jangan tampilkan detail teknis |
| `TableSkeleton`, `CardSkeleton` | Loading | |
| `ConfirmDialog` | Konfirmasi aksi destruktif | Wajib untuk hapus/cabut |
| `AuditTimeline` | Riwayat perubahan (mis. `LetterLog`) | |
| `DayArc` | Busur perjalanan matahari terbit→maghrib dengan penanda Dzuhur/Ashar (`components/widgets/day-arc.tsx`) | Client. Tanpa teks (daftar jam jadi legenda). Logika murni di `modules/falak/domain/posisi-matahari.ts` |
| `ModeToggle` | Pilihan Waktu Standar / Istiwa' dengan latar aktif yang bergeser | Dipakai widget beranda dan `/falak` |
| `StarLattice` | Pola bintang delapan sudut untuk latar hero | Dekoratif, `aria-hidden`, warna `currentColor` |
| `Stagger` / `StaggerItem` | Urutan masuk hero sekali saat dimuat | `components/motion/stagger.tsx` |
| `PageFade` | Fade 200ms antar-rute publik (`app/(public)/template.tsx`) | Hanya opacity |
| `ModuleCard` | Tautan modul di Ringkasan dashboard (judul + deskripsi) | `components/dashboard/module-card.tsx` |

## 9. Larangan Keras

- ❌ DILARANG membuat komponen duplikat — cek katalog dulu.
- ❌ DILARANG edit manual `components/ui/*`.
- ❌ DILARANG hardcode warna/spacing/role di komponen.
- ❌ DILARANG komponen domain mengimpor `infrastructure/` atau Prisma.
- ❌ DILARANG aksi destruktif tanpa `ConfirmDialog`.
- ❌ DILARANG meneruskan data sensitif (password, token) sebagai props.
