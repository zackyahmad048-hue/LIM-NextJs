## 2. Route Group

| Group | Isi | Layout | Akses |
| :--- | :--- | :--- | :--- |
| `(public)` | Portal, falak, verifikasi QR, form permohonan lembaga | Navbar + Footer | Tanpa login |
| `(auth)` | Login, lupa/reset password | Terpusat, minimal | Tanpa login |

## 4. Navigasi per Role

Menu dibangun dari izin role (helper permissions), bukan `if role === ...` tersebar.

| Kelompok role | Menu utama |
| :--- | :--- |
| `OWNER` | Semua modul |
| `ADMIN_SEKRETARIAT` | Persuratan, Kepengurusan, Falak (baca) |
| `TIM_WAJIB_KHIDMAH` | Wajib Khidmah, Permohonan |
| `CONTENT_MANAGER` | CMS, Dakwah Digital |
| `ADMIN_BIDANG_SAFARI` | Safari, Persuratan (buat/baca) |
| `ADMIN_BIDANG_PESANTREN_RAMADAN` | Pesantren Ramadan, Persuratan (buat/baca) |
| `PW`, `PC` | Persuratan, WK, Safari, Pesantren, Dakwah, Daerah Binaan, Kepengurusan (baca) — scope organisasi sendiri |
| `PONDOK_INTERNAL` | Falak (baca) `[ISI: menu lain]` |
| `LEMBAGA_EKSTERNAL` | Status permohonan, Laporan WK, Umpan balik |
| `GURU_BANTU` | Penugasan sendiri, Laporan mingguan, Falak |
| `PANITIA_SAFARI_DAERAH` | Approval jurnal wilayahnya |
| `DELEGASI_SAFARI_DAERAH` | Jurnal harian sendiri |
| `PENGAJAR_PESANTREN_RAMADAN` | Laporan harian sendiri |

Perilaku menu: item tanpa izin disembunyikan (bukan sekadar disabled). Menyembunyikan menu BUKAN pengamanan — server tetap memeriksa.

## 5. Pola Layout Halaman

| Tipe halaman | Pola | Contoh |
| :--- | :--- | :--- |
| Daftar | `PageHeader` + `FilterBar` + `DataTable` + `Pagination` | `/dashboard/letters` |
| Detail | `PageHeader` (judul + `StatusBadge` + aksi) + kartu info + riwayat/log | `/dashboard/letters/[id]` |
| Form | Satu kolom, grup field, aksi sticky di bawah (mobile) | Buat surat, input laporan |
| Dashboard ringkas | Grid kartu metrik + daftar tugas | `/dashboard` |
| Publik/Artikel | Single column, tipografi editorial | `/artikel/[slug]` |
| Auth | Split screen / kartu tengah | `/login` |

Setiap halaman data WAJIB punya empat state: **loading** (skeleton), **kosong**, **error**, **sukses**.

## 6. Template Spesifikasi Halaman

Salin untuk tiap halaman baru.

```md
### [Nama Halaman] — `/rute`
- **Modul:** 
- **Role & scope:** (mis. PW/PC 🏢, OWNER 🌍)
- **Tipe layout:** daftar | detail | form | dashboard
- **Data (query):** modules/<domain>/presentation/queries/...
- **Aksi (Server Action):** modules/<domain>/presentation/actions/...
- **Komponen utama:** 
- **State:** loading / kosong / error / sukses
- **Filter & sort (URL):** page, limit, q, status, sort
- **Responsif:** 
- **Catatan khusus:** (mis. wajib namaPengisi & jabatanPengisi untuk akun organisasi)
```

## 7. Alur Pengguna Utama

```text
Surat:        DIKETIK → REVIEW → APPROVED → SENT → ARCHIVED
              (nomor surat baru dibuat saat SENT — UI tidak menampilkan nomor sebelum itu)

Permohonan:   Form publik → DIAJUKAN → disetujui pusat → akun LEMBAGA_EKSTERNAL dibuat otomatis → login

Jurnal safari: MENUNGGU → DISETUJUI_PANITIA_DAERAH → DISETUJUI_PW_PC → DISETUJUI_KADES → LENGKAP

Konten dakwah: PW/PC upload → PENDING_REVIEW → APPROVED → PUBLISHED  (atau REJECTED)
```
