# CMS

**Domain:** Content Management System (CMS)

**Version:** 1.0

**Status:** Approved

---

# Overview

Content Management System (CMS) merupakan domain yang bertanggung jawab mengelola seluruh konten publik pada LIM Digital Platform.

CMS menjadi pusat pengelolaan informasi yang akan ditampilkan pada Website maupun Mobile Application.

Domain ini memungkinkan administrator membuat, mengubah, mempublikasikan, dan mengarsipkan berbagai jenis konten secara terstruktur.

---

# Objectives

Domain CMS bertujuan untuk:

- Mengelola konten website.
- Mengelola halaman statis.
- Mengelola berita dan artikel.
- Mengelola kategori konten.
- Mengelola tag.
- Mengelola media yang berkaitan dengan konten.
- Menyediakan konten untuk Website dan Mobile.
