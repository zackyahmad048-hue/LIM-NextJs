# Secretariat

**Project:** LIM Digital Platform

**Domain:** Secretariat

**Version:** 1.0

**Status:** Approved

---

# Overview

Domain Secretariat bertanggung jawab mengelola seluruh administrasi organisasi yang berkaitan dengan surat-menyurat, disposisi, arsip, dokumen resmi, dan layanan kesekretariatan.

Domain ini menjadi pusat administrasi internal organisasi dan terintegrasi dengan Domain Letter, Organization, Program, dan Certificate.

---

# Objectives

Domain Secretariat bertujuan untuk:

* Mengelola administrasi organisasi.
* Mengelola surat masuk dan surat keluar.
* Mengelola disposisi surat.
* Mengelola arsip administrasi.
* Mengelola dokumen organisasi.
* Menjadi pusat layanan kesekretariatan.

---

# Scope

Domain Secretariat mencakup:

* Incoming Mail
* Outgoing Mail
* Disposition
* Archive
* Official Documents
* Administrative Services
* Agenda Book
* Document Tracking

---

# Actors

Domain Secretariat digunakan oleh:

* Super Administrator
* Administrator
* Sekretaris
* Operator Sekretariat

Pengguna lain hanya dapat melihat dokumen sesuai permission yang dimiliki.
