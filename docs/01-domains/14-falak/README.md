# Overview

Domain Falak bertanggung jawab mengelola seluruh data, perhitungan, observasi, dan layanan yang berkaitan dengan ilmu falak (astronomi Islam) pada LIM Digital Platform.

Domain ini menyediakan layanan perhitungan waktu salat, arah kiblat, kalender Hijriah, hisab-rukyat, posisi matahari dan bulan, serta data astronomi lainnya.

Falak merupakan domain inti (Core Domain) yang mendukung pelayanan keagamaan berbasis data astronomi.

---

# Objectives

Domain Falak bertujuan untuk:

* Mengelola data astronomi.
* Menghitung waktu salat.
* Menghitung arah kiblat.
* Mengelola kalender Hijriah.
* Mengelola data hisab dan rukyat.
* Menyediakan API perhitungan falak.
* Menyediakan layanan observasi astronomi.

---
