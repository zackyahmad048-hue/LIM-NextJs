# Data Tables

Komponen tabel digunakan untuk menampilkan data dalam jumlah besar dengan struktur baris dan kolom. 

## Standar Fitur Tabel
1. **Pagination:** Gunakan server-side pagination (limit & offset/page) untuk data > 50 baris.
2. **Sorting:** Klik pada header kolom untuk *sort ascending/descending*.
3. **Filtering & Search:** Sediakan input *Search* global dan filter spesifik per kolom (opsional).
4. **Empty State:** Tampilkan ilustrasi dan pesan jelas jika data kosong (misal: "Belum ada data jadwal shalat").
5. **Actions:** Letakkan aksi (Edit, Delete, View) di kolom paling kanan atau gunakan *kebab menu* (tiga titik).
